# Code of Conduct

Mouzi is built in the open, and everyone should be able to participate without being treated badly.

This code of conduct applies to project issues, pull requests, discussions, reviews, and other spaces connected to the Mouzi community.

## Expected Behavior

Please:

* Treat other people with respect.
* Give constructive and specific feedback.
* Be patient with users and contributors of different experience levels.
* Assume good intent while still discussing technical disagreements honestly.
* Keep conversations relevant to the project.
* Respect people's privacy.

Disagreement is normal. Personal attacks are not.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment, threats, intimidation, or discrimination.
* Insults or personal attacks.
* Sexualized language or unwanted attention.
* Publishing another person's private information.
* Spam, deliberate disruption, or repeated off-topic comments.
* Abusing bug reports, pull requests, or other project tools.

## Enforcement

Project maintainers may edit or remove comments, reject contributions, lock conversations, or temporarily or permanently restrict participation when necessary.

Responses will depend on the context and severity of the behavior. Decisions are made to protect contributors and keep the project productive.

If you experience or witness unacceptable behavior, contact the project maintainer privately using a contact method listed on the [maintainer's GitHub profile](https://github.com/hsr88).

Please do not publish sensitive details in a public issue.

Reports will be reviewed as privately and fairly as possible. Retaliation against someone who makes a good-faith report is not acceptable.

## Scope

This code of conduct applies when participating in Mouzi project spaces or representing the project in public.
